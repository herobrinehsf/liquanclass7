## 📖 项目简介

这是一个纯静态的大学官网导航网站，收录了全国（含港澳台）普通高等学校的官方网站入口。
数据来源为教育部《全国高等学校名单》（截至 2025 年 6 月 20 日），
共 **2919 所**普通高校（其中本科 1365 所、高职专科 1554 所）。

**在线预览**：`https://你的用户名.github.io`

## ✨ 功能特性

| 特性 | 说明 |
|------|------|
| 🗺️ 按地区分组 | 华北 / 东北 / 华东 / 华中 / 华南 / 西南 / 西北 / 港澳台 |
| 🏫 省份独立页面 | 每个省级行政区一个独立 HTML，便于分享和收藏 |
| 🔍 全局搜索 | 支持校名、省份模糊搜索，输入即搜 |
| 🏷️ 智能标签 | 自动标注 211/985/双一流 / 本科 / 专科 / 民办 |
| 📱 响应式设计 | PC、平板、手机自适应 |
| ⚡ 零依赖 | 纯 HTML + CSS + JS，无框架、无构建步骤 |
| 🚀 一键部署 | 原生支持 GitHub Pages |
