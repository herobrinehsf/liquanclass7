## 📖 项目简介

这是一个纯静态的大学信息导航平台，为高中生择校、志愿填报提供一站式信息支持。
数据来源为教育部《全国高等学校名单》（截至 2025 年 6 月 20 日）和
人社部《企业薪酬调查信息（2025 年）》。

**在线预览**：`https://你的用户名.github.io`

## ✨ 功能特性

### 侧边栏导航

网站采用可唤出的侧边栏作为主导航，包含 7 大板块：

| 板块 | 图标 | 功能 |
|------|------|------|
| 大学官网直入 | 🏫 | 按地区/省份浏览全国高校，点击进入官网 |
| 强项学科分类 | 📚 | 按学科优势分类展示高校 |
| 招生路径分类 | 📋 | 强基计划、综合评价、专项计划等 |
| 校企对接特色 | 🏢 | 订单班、产业学院等就业直通路径 |
| 其它网站 | 🔗 | 预留给你自行添加的网站 |
| 大学数据详情 | 📈 | 录取分数折线图 + 招生人数趋势 |
| 职业薪资排行 | 💰 | 人社部官方薪酬数据可视化 |

### 核心功能

- 🔍 **全局搜索**：支持校名、省份模糊搜索，输入即搜
- 📊 **录取数据可视化**：Chart.js 折线图展示分数变化和招生人数
- 🏷️ **智能标签**：自动标注 211/985/双一流 / 本科 / 专科 / 民办
- 📱 **响应式设计**：PC、平板、手机自适应
- ⚡ **零构建**：纯 HTML + CSS + JS，无框架依赖
- 🚀 **一键部署**：原生支持 GitHub Pages
